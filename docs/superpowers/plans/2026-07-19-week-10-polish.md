## Task 3: Scroll-reveal via IntersectionObserver

- [ ] **`src/components/motion/FadeUp.astro`**

```astro
---
interface Props {
  delay?: number;
  class?: string;
}
const { delay = 0, class: className = '' } = Astro.props;
---

<div data-reveal style={`--reveal-delay:${delay}ms`} class:list={['opacity-0', className]}>
  <slot />
</div>
<style>
  [data-reveal] {
    transform: translateY(8px);
    transition:
      opacity 400ms cubic-bezier(0.16, 1, 0.3, 1),
      transform 400ms cubic-bezier(0.16, 1, 0.3, 1);
  }
  [data-reveal].is-revealed {
    opacity: 1 !important;
    transform: translateY(0);
    transition-delay: var(--reveal-delay);
  }
  @media (prefers-reduced-motion: reduce) {
    [data-reveal] {
      opacity: 1;
      transform: none;
      transition: none;
    }
  }
</style>
```

- [ ] **`src/scripts/reveal.client.ts`**

```ts
const obs = new IntersectionObserver(
  (entries) => {
    for (const e of entries) {
      if (e.isIntersecting) {
        e.target.classList.add('is-revealed');
        obs.unobserve(e.target);
      }
    }
  },
  { rootMargin: '0px 0px -10% 0px', threshold: 0.05 },
);

document.querySelectorAll('[data-reveal]').forEach((el) => obs.observe(el));
```

- [ ] **Include** the script in `PublicLayout.astro` only (not admin/ops):

```astro
<script src="../scripts/reveal.client.ts"></script>
```

- [ ] **Wrap** scent grid cards, reviews row, and story page paragraphs with `<FadeUp>`.

## Task 5: Accessibility audit

- [ ] **Install axe-playwright**: `npm install -D @axe-core/playwright`.

- [ ] **`tests/e2e/a11y.spec.ts`**

```ts
import { test, expect } from '@playwright/test';
import AxeBuilder from '@axe-core/playwright';

const ROUTES = [
  '/',
  '/scents',
  '/scent/azeziya',
  '/bundles/starter-set',
  '/story',
  '/contact',
  '/policies/shipping',
  '/policies/returns',
  '/policies/privacy',
  '/policies/terms',
  '/cart',
  '/checkout',
  '/auth/sign-in',
  '/auth/sign-up',
  '/auth/forgot-password',
];

for (const route of ROUTES) {
  test(`a11y: ${route} has no critical violations`, async ({ page }) => {
    await page.goto(route);
    const results = await new AxeBuilder({ page }).withTags(['wcag2a', 'wcag2aa']).analyze();
    const critical = results.violations.filter(
      (v) => v.impact === 'critical' || v.impact === 'serious',
    );
    if (critical.length) console.log(JSON.stringify(critical, null, 2));
    expect(critical).toEqual([]);
  });
}
```

- [ ] Run; fix every critical/serious finding. Common fixes:
  - Add `alt` to all `<img>`.
  - Replace `<div onclick>` with `<button>`.
  - Ensure form fields have associated `<label>`.
  - Increase contrast on `text-navy/60` if it fails AA on cream — bump to `/70` or `/80`.
  - Add `aria-current="page"` to active nav links.
  - Ensure `<dialog>` (if used) traps focus and restores on close.

let lastY = window.scrollY;
const bar = document.querySelector('[data-sticky-buy]');
window.addEventListener('scroll', () => {
  const y = window.scrollY;
  if (bar) {
    if (y > lastY && y > 80) bar.classList.add('translate-y-full');

  }
  lastY = y;
});
